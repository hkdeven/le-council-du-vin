What this is, underneath
  • ◇Live fields cannot live in an email. Gmail, Outlook and Apple Mail all strip them out, so the three questions sit one tap away instead, on a page of their own.
  • ◇The link in each letter is theirs alone. It names them to the app, so there is no login, no password and no magic link to go astray.
  • ◇It can write one thing only: that soul’s own offering, for that one night. It opens nothing else, and it dies when the night does.
  • ◇It writes to the same place the app already writes, so the Prophecy counts it, and nothing on the night behaves differently.
  • ◇Anyone who would rather use the app still can. This takes nothing away.
